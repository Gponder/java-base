***复杂度:***
**O(1) —— 常数级**
不随 n 增长
示例：
数组下标访问 arr[i]
特点：最快

**O(log n) —— 对数级**
每次缩小一半规模
示例：
二分查找
特点：数据越大优势越明显

**O(n) —— 线性级**
遍历一次数据
示例：
for 循环遍历数组

**O(n log n) —— 线性对数级**
常见于高效排序
示例：
快速排序（平均）
归并排序
特点：工程中最常见的高效复杂度

**O(n²) —— 平方级**
双重循环
示例：
冒泡排序
两层嵌套遍历

**O(n³) —— 立方级**
三重循环
示例：
一些暴力矩阵算法

**O(2ⁿ) —— 指数级**
每增加一个元素，计算量翻倍
示例：
子集枚举（暴力）
特点：非常慢

**O(n!) —— 阶乘级**
全排列问题
示例：
排列枚举
特点：最慢，基本不可用（n稍大就爆炸）

***直观对比（n = 10 时）***

复杂度	    大致操作次数
O(1)	    1
O(log n)	~3
O(n)	    10
O(n log n)	~30
O(n²)	    100
O(2ⁿ)	    1024
O(n!)	    3628800
